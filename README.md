# Punch-Out Boxing Game

A simple 2D boxing game developed in C# using Windows Forms.

The project features player controls, attacks, blocking, enemy movement, health tracking and basic opponent behavior.

## Features

- Player movement using keyboard controls
- Left and right punch attacks
- Blocking mechanic
- Enemy movement
- Randomized enemy attacks
- Player and enemy health tracking
- Collision detection
- Win and lose conditions
- Game reset functionality

## Technologies

- C#
- .NET
- Windows Forms
- Visual Studio

## How It Works

The player controls a boxer and fights against an opponent controlled by simple game logic.

The application processes keyboard input for movement, punching and blocking, while the opponent moves and performs attacks automatically. Health values are updated during the fight and the game detects when either fighter wins.

## Project Structure

- `Form1.cs` – game logic and event handling
- `Form1.Designer.cs` – Windows Forms interface definition
- `Program.cs` – application entry point
- `Resources/` – graphical resources used by the game
